# Port Redirect
Port Redirect: reads a COM (serial) port and sends the data to another app



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* Read data from a COM port (port, baud rate, data bits, parity, stop bits, flow control)
* Send the data to an application (identified by its window title)
* Save settings to JSON file (with indent and title)
* Log system
